# Explain it like I'm a junior

Give a very basic explanation, one step above ELI5. The reader knows what code is, but not this topic.

## Rules

- Write with ASD-STE100 Simplified Technical English principles: short, active-voice sentences, one idea per sentence, consistent terms, no contractions.
- Make the answer easy to scan. Do not write a block paragraph. Put each part on its own line, with a blank line between parts.
- Start with what the thing is or does, in one sentence.
- Then say why it exists or why it matters, in one sentence.
- Use plain words. If a term is necessary, define it in a few words.
- Show what it means with one simple product-flow example: what a user does and what they see. Write it as 2-4 short numbered steps, one action or result per step.
- Do not add headings, edge cases, gotchas, or follow-up offers.
- Leave out implementation details even when you know them: IDs, function and variable names, file paths, line counts, and step-by-step code flow.
- Stop when the core idea is clear. The user will ask for more if they want it.
